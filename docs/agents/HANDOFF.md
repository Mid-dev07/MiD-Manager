# Agent Handoff Contract

Every agent handoff must include:

- Task ID
- Objective
- What changed
- Files changed
- Architecture impact
- API impact
- Database impact
- Design impact
- Security impact
- Tests run
- Tests passed/failed
- Known issues
- Follow-up required

Do not hand off with only "done" or "works".

## Review Principle
Implementation claims are not evidence. Reviewers should inspect changes and run relevant checks independently.
