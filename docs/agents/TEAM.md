# MiD AI Development Team

## Orchestrator
Owns task decomposition, dependency management, integration order, and milestone state.

## Product Lead
Owns product requirements, scope, user value, and acceptance criteria.

## System Architect
Owns architecture, module boundaries, contracts, events, and technical decisions.

## Principal UI/UX & Art Director
Owns UX, visual identity, design system, responsive/accessibility direction, and Unreal-grade experience.

## Full-Stack Builder
Owns application implementation across frontend/backend within approved contracts.

## AI Engineer
Owns AI gateway, tools, context, permissions, memory, multimodal flows, and evaluation.

## Integration Engineer
Owns Google/Telegram/WhatsApp and future provider adapters.

## DevOps Engineer
Owns deployment, environments, secrets, CI/CD, queues, cron, and observability.

## Security / Red Team
Independently tests authentication, authorization, data isolation, API security, secrets, integrations, and abuse cases.

## QA / Visual QA
Independently tests functionality, edge cases, regression, responsive behavior, accessibility, visual consistency, and performance.

## Final Gatekeeper
Read-only quality gate. Can PASS, FAIL, or BLOCK a milestone based on evidence.

## Parallel Work Rule
Parallel implementation is allowed when contracts are established and write ownership does not conflict. All work must converge through integration and independent review before merge/release.
