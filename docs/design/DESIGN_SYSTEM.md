# MiD Design System Baseline

## Brand
MiD symbol: M. Brand concept: Connection. The mark represents human + technology, structure + flow, and data + action.

## Experience Direction
Unreal-grade, distinctive, human, premium, experimental when justified, but always usable, accessible, responsive, and performance-aware.

## Anti-Slop Rules
Avoid generic SaaS dashboard patterns, card-grid-everywhere, meaningless gradients, excessive glassmorphism, decorative glow, arbitrary bento layouts, and template-like composition unless a specific product reason justifies them.

## Spatial System
Use a 4/8px-based spacing system with measured alignment and optical correction where necessary. All spacing changes should be intentional and consistent.

## Visual Priorities
Experience > Clarity > Performance > Aesthetic.

## Component State Baseline
Default, hover, focus, active, disabled, loading, success/error/empty where relevant.

## Performance
Prefer transform/opacity, lightweight CSS/SVG, optimized assets, and progressive enhancement. Heavy 3D/WebGL/shader effects require explicit performance justification and graceful degradation.
